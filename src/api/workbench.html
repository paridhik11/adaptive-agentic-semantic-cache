    Actual application flow

    The bounded agent chooses local document tools, drafts from read evidence, runs workflow review and waits for your decision. Exact caching binds the full drafting request and source context.

    Reference replay and live mode

    Reference replay uses scripted responses to exercise the real application without external inference. Live mode uses an explicitly selected free model and your shared quota journal. The mode is always labeled.

    What the counters mean

    Call counts include planning, drafting and workflow review. Draft hits are actual cache events. Timing shows local processing and is not a representative latency-savings result. Human approval here is a workflow decision, not independent evaluation.

    Still being evaluated

    General semantic reuse, independently reviewed live quality and representative end-to-end savings. This demo makes no percentage cost or latency claim.
