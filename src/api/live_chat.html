How reuse and timing work

A fresh request goes to the free OpenRouter model. Eligible answers stay cached for one hour. Short definitions can reuse a saved answer across wording changes and clear typos when the answer defines the same topic. Optional local models check broader rephrasings. Follow-ups and time-sensitive requests go to the model. The chat uses model knowledge, with no web search.

Response time measures server-side processing from cache lookup through the returned answer. Provider time includes the free-provider call and its quota journal. Fresh and repeat timings are shown for the matching question.
