How reuse and timing work

Fresh questions go to the free OpenRouter model. Eligible answers stay cached for one hour. Definitions can match across wording and clear typos. Comparisons can match when both terms and their order agree. Optional local models check broader definition rephrasings.

Automatic context recognizes short follow-ups like “Give me an example.” Follow-ups and time-sensitive requests go to the model. The chat answers from model knowledge.

Response time includes any wait for a provider slot. Provider time starts when the slot opens and includes journal handling.
