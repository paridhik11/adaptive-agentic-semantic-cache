    Evidence and methodology

    Each workload event was matched across four configurations using its event ID and request metadata. Latency uses the campaign convention: median and exclusive p95, with the maximum reported for fewer than 20 samples. Adversarial intervals are exact 95% Clopper–Pearson intervals. Requests cluster by base intent and source group, so these intervals are descriptive under a binomial assumption.

    Repeat-heavy adversarial results are development regression evidence. Lower-repeat results describe the committed offline breadth replay. The campaign has zero independently reviewed accepts, so the answer-level incorrect reuse rate is unavailable. These logs provide no production traffic, billable usage or live quality estimate.
