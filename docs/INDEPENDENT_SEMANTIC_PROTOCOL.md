# Independent semantic evaluation protocol

Freeze before scoring development. Baseline is b6b9a946. Keep original ComQA test, historical interview receipts and authored fixtures as replication only. No live inference or weight training. Evaluate the following locally pinned policies on identical priming inputs. Publish counts, candidate traces using IDs, and separate equivalence scores.

- A is the unchanged optional live API with fixture transport, including its real admission rules. Also run exact mode. A separate full-question top-one baseline uses the published 0.84 cosine, 0.80 bidirectional pair, 0.85 bare-answer passage checks and existing requirement guards.
- B scans the top five dense candidates under those gates. C ranks by 0.75 dense cosine plus 0.25 TF-IDF word uni/bigram cosine and checks the same gates. Reject ambiguous qualifying candidates within 0.035 retrieval score and unresolved close candidates outside K for multi-candidate arms.
- D uses B and a relative passage gate for short answers of at most 12 words. Preserve the original absolute pass. Otherwise require both question-pair directions at least 0.95, bare-answer relevance at least 0.01, and incoming passage logit at most 0.5 below the original question's logit on the same answer. This tests whether a relative score transfers across paraphrases when both bare-answer scores are small.
- E adds answer-type and explicit tool checks to B. Use a question's explicit interrogative class (time, person, place, quantity) to reject incompatible types and require profiling evidence when requested. Keep the original passage cutoff. F combines only components with increased correct hits and zero additional incorrect decisions over the top-one baseline on development for both answer panels. Evaluate the combination on development and revert F to the baseline if it fails the same rule. Freeze F before any holdout scoring. Report all fixed arms on holdout. Reject a serving recommendation if any new incorrect decision appears, if precision's lower exact 95% bound is below 98%, or if source provenance and answer sufficiency cannot be reproduced at serving time.

Use two answer panels. In ComQA's public training file, remove questions and answer sets exposed in official development/test. Select by salted hash, group by cluster and exclude overlapping answer strings or duplicate questions across selected groups. Each split takes up to 128 distinct multi-question groups, each with a seed and first different question. Alternate groups between two primed cache shards. Probe each question once with its own shard and once with the other shard, where no annotated answer is available. Add an exact repeat per group in its own shard as a separate control. Matching stored answer sets are the short-answer endpoint. Disjoint strings are annotated errors and can miss real aliases.

The second panel uses Python 3.12.10 documentation's published interactive examples. Extract isolated literal expressions with unambiguous literal output and no variables, external state or function calls. Parenthesize the expression in the probe, preserving its AST and exact expected output. Only distinct outputs within a panel, cap at 40 per split. Hold whole source documents together. Evaluate the same two shards and exact repeats. This is a controlled syntax-invariance task with a publisher answer oracle. It does not establish natural-language procedural answer adequacy.

PAWS-Wiki test and GLUE QQP validation supply question/sentence equivalence only. Filter known repository pair/stream text, partition connected sentence components before sampling up to 128 pairs per class per split. Preserve original class labels, report precision, recall, specificity and confusion counts for cosine, bidirectional pair scoring, and their structural conjunction. Disclose training contaminations and balanced sampling.

Record rank, retrieval scores, structural outcome, bidirectional pair scores, passage logit/probability, source baseline, gate and annotation agreement for the intended and shortlisted candidates, even when they would have failed an earlier gate. Offline scorer work is shared and timed, so model-work estimates from cached measurements are distinct from measured live-handler fixture latency. Include per-arm outcomes and binomial exact intervals. The two contexts per probe are dependent. Never count estimates as observed API calls, paid cost or production time saved.

### Frozen supplemental checks

After development selected the relative short-answer rule and before scoring the holdout, add a corruption stress test. For each pair, keep the matching stored question but substitute an answer from another selected group. Pick the closest other seed to the original seed in cosine space, preferring the same explicit question type when available. ComQA groups have disjoint annotations, and Python groups have distinct displayed outputs. Run every policy on the same single corrupted entry. Report these outcomes separately. Any accepted corrupted answer blocks serving promotion. The selection and all thresholds are already frozen. Time all offline research arms independently, instrumenting local verification and actual in-process fallback invocations, and verify their decisions against the batch traces.
